# Security Policy

AgentShield MCP Inspector Lite is a security inspection tool, so responsible reporting matters.

## Reporting a vulnerability

Please avoid opening a public issue for a vulnerability that could expose users, credentials, files, or systems.

Instead, contact the project owner through the official TYKAIRO AI / Mahmoud Hisham channels listed on the organization profile and include:

- affected version
- reproduction steps
- expected vs actual behavior
- impact
- any safe proof-of-concept details

Please do not include real secrets, private tokens, or third-party confidential data.

## Scope

Reports concerning the public Lite repository are in scope. The private Pro codebase is not published here.

## Important note

A `SAFE` result from AgentShield Lite is not a guarantee that software is secure.
